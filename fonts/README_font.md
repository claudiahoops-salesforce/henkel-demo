# GT Flexa

GT Flexa is a commercial typeface from Grilli Type (https://www.grillitype.com/font/gt-flexa) and
can't be redistributed from this repo without a licence. Henkel owns/licenses it for its own site.

Add the web-font files here with these exact names (woff2):

- GT-Flexa-Regular.woff2   (400)
- GT-Flexa-Medium.woff2    (500)
- GT-Flexa-Bold.woff2      (700)

`styles.css` already declares the @font-face rules. If a file is missing the page falls back to Helvetica/Arial.
If Henkel uses other weights/widths (Flexa has Standard + Expanded + Light/Thin/Black), add more @font-face blocks.
